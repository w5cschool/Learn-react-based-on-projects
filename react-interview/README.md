# React 面试知识库

React 面试学习框架，按模块组织，便于系统复习。

## 目录结构

```
react-interview/
│
├── 00-mindset/           # 面试思维（多数人忽略）
├── 01-react-core/        # React 核心原理
├── 02-hooks/             # Hooks（面试最高频）
├── 03-component-design/  # 组件设计
├── 04-performance/       # 性能优化（中高级必问）
├── 05-router-ssr/        # Router & SSR
├── 06-state-management/  # 状态管理
├── 07-engineering/       # 工程能力（高频）
├── 08-project-experience/# 项目经验（最重要，决定 offer）
├── 09-source-code/       # React 源码（高级）
├── 10-system-design/     # 系统设计（大厂）
├── 11-coding-practice/   # Coding Practice
├── 99-cheatsheet/        # 面试速查表（面试前 10 分钟看）
├── answer-templates/     # 面试答题模板库（避免临场崩盘）
└── project-to-interview/ # 项目经验→面试题映射（长期护城河）
```

## 面试回答公式

1. **场景** - 在什么情况下遇到的
2. **问题** - 具体是什么问题
3. **方案** - 你怎么解决的
4. **优化** - 有没有进一步优化
5. **结果** - 最终效果如何
